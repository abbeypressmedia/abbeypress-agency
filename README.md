# AbbeyPress Agency

A conversion-focused ecommerce agency website built with Next.js.

## Stack
- Next.js 16
- React 19
- TypeScript
- CSS

## Development

Run `npm install` then `npm run dev`.

## Before launch

Update `lib/site-config.ts` with your real:
- business email
- WhatsApp number in international digits (for example Nigeria numbers use 234...)
- display label if desired

The contact page uses direct WhatsApp and email links. No lead data is stored until a database/email service is intentionally connected.
